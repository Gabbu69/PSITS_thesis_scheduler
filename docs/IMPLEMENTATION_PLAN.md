# Implementation plan

1. PostgreSQL schema and migrations; Better Auth credential sessions; coordinator, faculty and student server-side scopes; core record forms.
2. Explicit availability windows and recurring rules, date overrides and blocks; room directory; independent advising and defense limits.
3. One pure shared validator, deterministic bounded slot search, editable drafts and atomic publication under a college-wide PostgreSQL transaction lock.
4. Snapshot-backed versions and rescheduling; in-app notices, audit trail, scoped PDF and CSV exports.
5. Constraint acceptance tests, database concurrency and authorization integration tests, production build, browser workflow and sample report QA.

Brand: supplied PSITS logo; navy, cyan and soft neutral surfaces. Soft raised panels, restrained shadows, readable contrast and light/dark/system preference. The generated design suggestion was too oriented toward a marketing landing page; the product uses an academic operations dashboard instead. No paid integrations or hosted-site dependency.
